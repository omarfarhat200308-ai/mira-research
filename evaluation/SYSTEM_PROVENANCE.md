# System provenance: what the evaluated MIRA run actually used

**Question:** the interim report (v1, 2026-09-30) and `MIRA_Overview_v2.docx` (2026-07-07) describe Claude, PostgreSQL, Docker, IndicTrans2/Aksharamukha; a newer note says Groq/NVIDIA locally with none of those. Decided from evidence only.

**Verdict.** The outputs the Rater-1 worksheet displays are, case for case, the outputs of the **2026-09-11 local harness run on Groq and NVIDIA-NIM-hosted models, with no PostgreSQL, no Docker, no Claude, no IndicTrans2/Aksharamukha**. The report's technology paragraph (§2.3) matches the July *design overview*, not the evaluated system. The repo's own README (updated 2026-09-19, i.e. before the report) already says so.

Key proof chain: (1) Rater-1 workbook MIRA cells == `eval/results/final` for 29/29 non-B2 cases → (2) `final` records join 30/30 by `case_id` to `logs/2026-09-11.jsonl` → (3) those logs record provider/model per agent call: groq 165, nvidia 105, gemini 3, **anthropic 0**.

Confidence key: **HIGH** = directly recorded in a primary artifact; **MED** = strong inference from artifacts; **LOW** = absence of evidence only.
